# Créditos de terceiros

## DiscordDiceBot — dados poliédricos 3D

As imagens em `public/dice/source/blue` e os arquivos RGBA derivados em
`public/dice/raw` usam o conjunto `polyhedral_3d_blue_and_white` do projeto
[DiscordDiceBot](https://github.com/twonirwana/DiscordDiceBot), mantido por
twonirwana e distribuído sob a GNU Affero General Public License v3.0.

O texto integral da licença está em `DiscordDiceBot-AGPL-3.0.txt`. O README do
projeto de origem informa que os dados `polyhedral_3d` foram adaptados do modelo
publicado em https://blendswap.com/blend/16634.

Os arquivos `.rgba` preservam os mesmos pixels das imagens PNG e existem apenas
para que o Cloudflare Worker possa montar rapidamente uma faixa com os resultados.
